# Boost Engine — Universal Tech Solutions Architecture Context

## Brand Identity & Vision
- **Brand Name**: Boost Engine
- **Core Tagline**: "Problem Koi Bhi Ho — Tech Se Hum Solve Karenge."
- **Positioning**: Universal Tech Solution Provider. Business, Automation, Mobile Apps, Web, Cloud, AI & Hardware/IoT integration.

## Tech Stack & Architecture
- **Framework**: Vite + React
- **Backend / Cloud**: Firebase (Firestore for problem inquiries/leads, Firebase Hosting, Analytics)
- **Styling**: Tailwind CSS + Custom Neon/Glow CSS Utilities
- **Animations**: 
  - Pure HTML5 Canvas 2D/3D Math engines (Ultra lightweight, <15KB footprint)
  - Scrollytelling Frame Sequencer (RequestAnimationFrame canvas scrubbing)
  - Framer Motion for UI micro-interactions
  - Lucide React for consistent icons
- **Performance Targets**: 
  - Lighthouse Score: 95+
  - First Contentful Paint: < 0.8s
  - 60 FPS smooth scrolling on canvas animations

## Core Website Sections
1. **Navbar**: Sleek glassmorphism header with logo, navigation links, and "Get Solution" CTA.
2. **Hero Section**: 
   - Tagline: "Boost Engine: The Universal Tech Problem Solver"
   - Interactive Cybernetic Canvas Particle/Wave background (cursor-reactive)
   - Dual CTAs: "Explore Solutions" & "Throw Us Your Problem"
3. **Interactive Problem Solver Simulator (The Engine Terminal)**:
   - Interactive terminal where users can select or type business bottlenecks (e.g., "Manual Accounting", "Slow Sales", "No Mobile App")
   - Instant visual solution architecture breakdown.
4. **Scrollytelling Frame-Sequence Section (The Canvas Engine)**:
   - Apple-style frame sequence scroll effect illustrating the transformation pipeline:
     - Stage 1: Problem Intake & Diagnosis
     - Stage 2: Tech Architecture & Code Synthesis
     - Stage 3: Automated Engine Deployment
     - Stage 4: Exponential Scale & Results
5. **Solutions Matrix & Showcase**:
   - Mobile Solutions (Flagship showcase: *Thaaro Hisab* app)
   - Cloud Infrastructure & Enterprise Software
   - AI & Custom Automation Pipelines
   - Growth & Speed Optimization Engines
6. **Live Impact / ROI Metric Counter**:
   - Numbers that scale as user scrolls (Hours saved, revenue boosted, uptime).
7. **Interactive Inquiry / Problem Submission Portal**:
   - Multi-step frictionless form to submit problems directly.
8. **Modern Tech Footer**:
   - Quick links, status pill ("All Systems Operational"), social links, and copyright.
