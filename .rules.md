# Project & Assistant Rules: Boost Engine

## Global Communication & Execution Rules
1. **Language**: Communicate primarily in Hinglish (casual, friendly, professional developer tone: "Bhai", "Karo", "Setup", etc.).
2. **Terminal & Scripts**: 
   - **DO NOT run terminal execution scripts or package manager commands directly.**
   - Always output clean, copy-pasteable PowerShell/Bash commands for the user to execute in their local terminal.
   - The user will execute them and report back.
3. **Backend & Cloud**:
   - Use **Firebase** for backend, database (Firestore), user inquiries / problem submissions, analytics, and hosting.
   - Firebase MCP is enabled in the workspace.
4. **Performance First (Weight & Speed)**:
   - Keep the bundle ultra-lightweight.
   - Avoid bloated 3D libraries (like full Three.js packages) unless absolutely essential. Prefer pure HTML5 Canvas math algorithms, offscreen canvas rendering, and optimized frame sequencers.
   - All image sequences for scrollytelling must use WebP / optimized compressed frames or procedural rendering.
   - 60 FPS performance is mandatory.
5. **Code Quality**:
   - Modular React components with clean separation of concerns.
   - Tailwind CSS for modern responsive styling with dark tech / cyberpunk accents (electric blue, neon violet, deep obsidian background).
